# My JavaScript Projects

## 🚀 Projects Overview

This repository contains six of my recent JavaScript projects showcasing various functionalities and interactive web solutions. Each project demonstrates my learning journey at Sheriyan's Coding School, where I developed practical skills in web development.

---

### Projects:

1. **QR Code Generator**  
   - **Functionality**: Generates QR codes dynamically from input text.  
   - **Key Functions**: `generateQRCode(text)`, `downloadQRCode()`, `previewQRCode()`  
   - **Website**: [QR Code Generator](https://qrgenerator1-olive.vercel.app/)

2. **Analog Clock**  
   - **Functionality**: Displays a real-time analog clock.  
   - **Key Functions**: `updateClock()`, `setInterval()` for real-time updates, `formatTime()`  
   - **Website**: [Analog Clock](https://analogclock2.vercel.app/)

3. **Calculator**  
   - **Functionality**: Performs basic arithmetic operations such as addition, subtraction, multiplication, and division.  
   - **Key Functions**: `add()`, `subtract()`, `multiply()`, `divide()`  
   - **Website**: [Calculator](https://calculator-two-chi-80.vercel.app/)

4. **Password Generator**  
   - **Functionality**: Generates strong passwords with customizable length and character types (lowercase, uppercase, numbers, symbols).  
   - **Key Functions**: `generatePassword(length, options)`, `validatePassword()`, `saveToClipboard()`  
   - **Website**: [Password Generator](https://passwordgenerator-five-jet.vercel.app/)

5. **Stopwatch**  
   - **Functionality**: A simple stopwatch with start, stop, and reset functionalities.  
   - **Key Functions**: `startTimer()`, `stopTimer()`, `resetTimer()`  
   - **Website**: [Stopwatch](https://stopwatch-rosy-pi.vercel.app/)

6. **To-Do List**  
   - **Functionality**: Manages tasks with options to add, edit, delete, and mark tasks as completed.  
   - **Key Functions**: `addTask()`, `editTask()`, `deleteTask()`, `toggleComplete()`  
   - **Website**: [To-Do List](https://to-do-list-two-brown-19.vercel.app/)
